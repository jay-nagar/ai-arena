# Orrery

Orrery is a cinematic browser prototype for an autonomous faction arena. It models 128 characters across eight viable teams, with visible diplomacy, conflict, recruitment, defections, mergers, schisms, leadership votes, and explainable decision summaries.

The Overseer can influence beliefs, loyalties, fears, ambitions, relationships, governance, and world events without directly scripting character choices. The prototype runs entirely locally and needs no AI API key.

## Run locally

```bash
npm install
npm run dev -- --port 43127
```

Open [http://localhost:43127](http://localhost:43127).

## Commands

- `npm run dev` — start the development server
- `npm run build` — create a production build
- `npm run lint` — run ESLint
